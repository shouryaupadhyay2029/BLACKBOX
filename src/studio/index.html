⚡ INSTALLATION, SETUP & INTEGRATION BLUEPRINT

Set up Blackbox in
under 60 seconds

Whether you want to test the interactive sandbox right now, wrap your own local application, or wire autonomous AI agents via Model Context Protocol (MCP) — follow these 4 steps.

STEP 01 · INSTALL ZERO HEAVY DEPS

Install Globally or Link from Source

Clone the repository and run npm link to make the blackbox and blackbox-mcp binaries globally available, or install directly via npm / pnpm.

Method A: Global Package Install (npm / pnpm / npx) 
npm install -g blackbox-flight-recorder
# Or with pnpm / npx:
pnpm add -g blackbox-flight-recorder
npx blackbox-flight-recorder demo
Method B: From Source Repository (macOS / Linux / Windows) 
git clone https://github.com/shourya-upadhyay/blackbox.git
cd blackbox
npm install && npm link   # or ./install.sh | .\install.ps1
STEP 02 · ONBOARD & SUPERVISE NODE · PYTHON · GO · RUST

1-Command Project Setup or Instant Demo

Run blackbox init --inject inside any repo to scaffold .blackbox, MCP configs, and Browser SDK, or wrap your dev server with blackbox run.

Option 1: 1-Command Project Onboarding + Supervision 
# Auto-creates .blackbox, .cursor/mcp.json & injects Browser SDK:
blackbox init --inject

# Supervise dev server + attach HTTP Wiretap (4000 -> 3000):
blackbox run "npm run dev" --proxy 4000:3000
Option 2: Instant Interactive Demo Sandbox (:9876 + :4400) 
blackbox demo
# Boots Studio UI at http://localhost:9876 + Sandbox at :4400
STEP 03 · BROWSER SDK DOM + FETCH INTERCEPTOR

Add the 1-Line Browser Flight Recorder

Drop this script tag into your frontend's index.html or root layout.tsx. It captures DOM snapshots, user clicks, console errors, and injects X-Blackbox-Trace-Id into every network call.

Frontend HTML / Layout Script Tag 
<script 
  src="http://localhost:9876/sdk/browser-agent.js" 
  data-blackbox-endpoint="http://localhost:9876"
></script>
✓ Auto-Injects X-Blackbox-Trace-Id ✓ Captures DOM & Click Coordinates ✓ Alt+Shift+B Hotkey HUD
STEP 04 · AI AGENTS (MCP) CLAUDE · CURSOR · WINDSURF

Connect Autonomous Coding Agents via MCP

Plug Blackbox's native stdio JSON-RPC 2.0 MCP server into Claude Code or Cursor. Ask your agent: "Inspect the latest crash with Blackbox and fix the bug" for a 1-shot patch.

Claude Code CLI Setup 
claude mcp add blackbox -- blackbox mcp
Cursor / Windsurf (.cursor/mcp.json) 
{
  "mcpServers": {
    "blackbox": {

    }
  }
