STAGE 01 — INGESTION
Browser Agent & Gesture Tap

The lightweight browser client SDK captures user DOM clicks, input field mutations, page navigation, window.onerror, and unhandled promise rejections. Full DOM snapshots and Local/Session Storage states are recorded at sub-millisecond precision.

  • Automatic click laser coordinate calculation (X/Y relative positioning)
  • Lightweight snapshot sanitization of sensitive form passwords
  • Zero network interference via non-blocking WebSocket pipeline
STAGE 02 — WIRETAP
PTY Process & Reverse Proxy

Subprocesses (Node, Vite, Next.js, Python, Go) are executed inside an OS-level pseudo-terminal (PTY) capturing raw stdout/stderr streams. An inline transparent reverse proxy intercepts HTTP/WS traffic and stamps x-blackbox-trace correlation tokens.

  • Coalesces micro-burst stdout/stderr chunks into discrete lines
  • Correlates frontend fetch/XHR with exact backend controller endpoints
  • Preserves ANSI color escapes and process exit codes
STAGE 03 — TELEMETRY
60-Second In-Memory Ring Buffer

High-frequency multi-plane telemetry is ingested into a circular in-memory buffer (KalaRingBuffer). Stale events past the 60-second horizon are continuously evicted in O(1) time without triggering garbage collection spikes.

  • Zero SSD disk writes during standard operation
  • Fixed memory footprint (< 25MB under heavy load)
  • High-resolution monotonic timestamps (process.hrtime.bigint)
STAGE 04 — HEURISTICS
Causal Anomaly & Crash Detection

The anomaly engine monitors the rolling buffer for HTTP 5xx codes, Node V8 unhandled errors, fatal process exits, or manual triggers (Alt+Shift+B). Applies a grace-window delay to capture the complete cascade before freezing an immutable capsule.

  • Bi-directional temporal causality matching algorithm
  • 800ms post-crash grace period catches lingering async callbacks
  • Bakes standalone .blackbox.json bundle with full Git diff
STAGE 05 — REPLAY
4-Plane Synchronized Time-Travel

The Blackbox Studio provides millisecond-synchronized horological time-travel across 4 aligned planes: Sandboxed DOM Replay with laser reticles, HTTP/WS Waterfall, Source Code X-Ray stack locator, and Git Working Tree Differ.

  • Plane I: DOM Viewport with auto-fit viewport scaling
  • Plane II: Waterfall with request/response payload inspector
  • Plane III: Source code line highlighter and V8 stack trace jump
  • Plane IV: Git working tree inspector and AI diagnostic preview
STAGE 06 — AGENTIC
Autonomous AI Diagnostic & MCP Server

Synthesizes an executive Markdown Root-Cause Dossier with culprit code lines, error causality, and reproduction steps. Connects directly to Claude Code, Gemini CLI, Cursor, and Windsurf via standard Model Context Protocol (MCP).

  • Structured Markdown packet ready for direct LLM context ingestion
  • Native stdio Model Context Protocol (MCP) server integration
  • Eliminates debugging hallucinations with ground-truth localhost telemetry
